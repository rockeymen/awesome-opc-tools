# 免费方案与费用说明

这份文档记录部分工具的费用结构和容易误解的限制，帮助读者从用途目录进入选型。未列出的工具不代表免费，也不代表没有限制。

本页下表于 **2026-10-22** 查阅所链接的官方资料。仅核对公开说明，未逐项注册或实测；后续使用时请重新确认官方定价与条款。

## 先区分费用类型

| 类型 | 含义 |
| --- | --- |
| 免费版 | 有持续可用的免费套餐，但通常有功能或用途限制。 |
| 免费额度 | 一定资源量以内免费，超出后可能计费、限制使用或要求升级。 |
| 免费试用 | 在期限或试用额度内体验，不能当作长期免费方案。 |
| 开源自部署 | 按许可证使用软件，服务器、数据库、备份和维护另计成本。 |
| 付费服务 | 按订阅、席位、资源用量等收费，具体维度需要查看定价页。 |

开源许可、能否自部署、云服务如何收费应分别记录。一个产品可能同时提供多个版本。

## 邮件服务的额外区别

域名邮箱、邮件转发、事务邮件和营销邮件的权限不同。转发到已有邮箱，并不自动获得用该域名地址回复或批量发信的能力。

Cloudflare 原 Email Routing 文档当前归入 [Email Service](https://developers.cloudflare.com/email-service/)，官网同时列出路由和 Beta 发信能力。使用时查看对应功能的开通条件与限制，不要把邮件路由配置直接当作完整邮箱。

## 如何维护

- 变更费用说明时，同时更新官方来源和该条目的核验日期。
- 精确额度应注明计量单位、周期、套餐和条件；不只写一个价格数字。
- 官网读取失败或信息不明确时，标为「待核验」，不要猜测。
- 国内访问、绑卡和注册资格只在有明确证据时记录；个人体验要写明日期与环境。
